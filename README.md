# Hyderabad Food Trail 🍛

## About the Project
Hyderabad Food Trail is an interactive website that showcases the famous dishes and culinary culture of Hyderabad, Telangana.

## Features
- Explore famous Hyderabadi dishes.
- Filter food by category.
- Filter by vegetarian and non-vegetarian preferences.
- Switch between day and night themes.
- Discover interesting food facts.
- Take an interactive food personality quiz.
- Enjoy an attractive and user-friendly design.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Files
- `index.html` – Main webpage
- `style.css` – Website styling
- `script.js` – Interactive functionality
- `data.js` – Food information
- `favicon.svg` – Website icon

## How to Run Locally
1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Explore the website features.

## Deployment
The website is hosted using GitHub Pages, a free service for publishing static websites.
