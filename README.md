# 🍛 Hyderabad Food Trail

## 📌 About the Project

Hyderabad Food Trail is an interactive website that showcases the famous dishes and culinary culture of Hyderabad, Telangana. It offers a fun way to explore local food traditions through an engaging and visually appealing experience.

## 🌐 Live Website

[https://manikyasumanasri-lgtm.github.io/hyderabad-food-website/](https://manikyasumanasri-lgtm.github.io/hyderabad-food-website/)

## ✨ Features

- 🍽️ Explore famous Hyderabadi dishes.
- 🔍 Filter dishes by food category.
- 🌱 Filter food by vegetarian and non-vegetarian preferences.
- 🌞 Switch between day and night themes.
- 💡 Discover interesting food facts.
- 🎯 Take an interactive food personality quiz.
- 📱 Enjoy a user-friendly website design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 How to Run Locally

1. Clone or download the project files.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website and its features.

## ☁️ Deployment

This website is hosted using GitHub Pages, a free hosting service for static websites.

The website is deployed from the `main` branch using the root folder (`/(root)`).
