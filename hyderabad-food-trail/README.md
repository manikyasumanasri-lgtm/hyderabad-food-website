# Hyderabad Food Trail

A beautifully designed, scroll-driven web journey through the culinary streets of Hyderabad.

**Live Demo:** [https://<username>.github.io/hyderabad-food-trail/](https://<username>.github.io/hyderabad-food-trail/)

## 🥘 Features
- **Interactive Trail:** Scroll through iconic dishes mapped along a winding path.
- **Theming:** Toggle between Day (Cream) and Night (Charcoal) themes.
- **Filtering:** Quickly filter dishes by main course, snacks, sweets, or drinks.
- **Ratings:** Rate dishes and save your preferences locally.
- **Personality Quiz:** Answer questions to find out which Hyderabadi dish you are!
- **Zero Dependencies:** Built entirely with plain HTML, CSS, and Vanilla JavaScript.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Variables, Animations, Flexbox, Media Queries)
- Vanilla JavaScript (DOM manipulation, LocalStorage, Web Share API, Canvas Confetti)
- Inline SVGs (No external image requests)

## 🚀 How to Run Locally
There is no build step or backend required!
1. Clone this repository or download the files.
2. Double click on `index.html` to open it in any modern web browser.
3. Enjoy the trail!

## 🌐 Deploying to GitHub Pages

GitHub Pages is a fast, free hosting service provided by GitHub for static websites.

**Steps to Deploy:**
1. Push this repository to your GitHub account.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under "Build and deployment", select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder.
5. Click **Save**. In a few minutes, your site will be live!

### GitHub Pages FAQ
* **What is GitHub Pages?** It's a static site hosting service that takes HTML, CSS, and JavaScript files straight from a repository on GitHub and publishes a website.
* **Can it host dynamic apps?** No, it does not support backend languages like PHP, Python, or Ruby, nor databases. It is strictly for static files.
* **What are its limits?** Recommended limit of 1GB repository size, a soft limit of 100GB bandwidth per month, and 10 builds per hour.
* **How do I update the site?** Simply commit and push changes to your branch. GitHub Pages will automatically rebuild and update your live site.
* **What happens if the repo is deleted?** The hosted website will be taken down immediately.
* **What is the default file?** `index.html` is served as the default root page.
* **Can I use a custom domain?** Yes! You can configure a custom domain in the repository's Pages settings and add a `CNAME` file.
