# Hyderabad Food Trail 🍛

## About the Project
Hyderabad Food Trail is an interactive website that showcases the famous dishes and culinary culture of Hyderabad, Telangana.

## Features
- Explore Hyderabad's famous foods.
- Filter dishes by food category.
- Filter by vegetarian and non-vegetarian preferences.
- Switch between day and night themes.
- Discover interesting food facts.
- Take an interactive food personality quiz.
- Enjoy a clean and attractive user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Project Files
- `index.html` – Main webpage
- `style.css` – Website styling
- `data.js` – Food data
- `script.js` – Interactive functionality
- `favicon.svg` – Website icon

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore the website.

## Deployment
This project uses GitHub Pages, a free hosting service for static websites.
